# Voice Log Calendar

ボイストレーニングの記録を「日付」に紐づけて保存・振り返るためのWebアプリです。

- 月カレンダー表示（記録ありの日に ● マーカー）
- 日次詳細（メモ / 課題）
- 録音（MediaRecorder）
- 音声アップロード / 再生 / 削除
- ブラウザ内ストレージに永続化（オフラインで利用可）

## 開発環境

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてください。

## 使い方

1. 左のカレンダーで日付を選択
2. 右の「今日のメモ」「今日の課題」を編集 → 保存
3. 「録音開始」→「停止」で録音を保存
4. 「アップロード」から既存音声ファイルも保存可能

## 注意点

- 録音にはマイク権限が必要です（拒否すると録音できません）
- データはこのブラウザ内に保存されます（サーバー送信はしません）
- ブラウザによって保存容量上限があります（大きい音声を大量に入れると失敗することがあります）

## データを消したい場合

Chrome系の場合:

- DevTools → Application → Storage → IndexedDB → `voice-log-db` を削除
